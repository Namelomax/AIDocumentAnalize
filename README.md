# Инспектор ИИ

Веб-сервис автоматической сверки строительной документации: проверяет
проектные и исполнительные документы на соответствие нормативным
требованиям и друг другу с использованием ИИ.

## Требования к окружению

- Docker с установленным NVIDIA Container Toolkit.
- На проверочном стенде используется GPU NVIDIA H100 80 ГБ.

## Как запустить

### На машине с интернетом

```bash
docker compose up
```

Сервисы `api`, `worker` и `web` соберутся из исходников, остальные образы
будут скачаны. Интерфейс открывается на `http://localhost:8080`.

> После правки исходников запускайте `docker compose up --build`: у `api`,
> `worker` и `web` задано поле `image:`, поэтому при обычном `up` компоуз
> возьмёт уже собранный образ и изменений в контейнере не окажется. Все переменные окружения по умолчанию заданы прямо в
`docker-compose.yml` (по значениям из `.env.example`), файл `.env` не
обязателен — создавайте его только если нужно переопределить какие-то
значения (например, пароли для боевого окружения).

### На проверочном стенде без интернета

Поставка включает архив образов `dist/inspector-images.tar`, собранный
заранее командой `scripts/build-offline-bundle.sh`.

```bash
docker load -i dist/inspector-images.tar
docker compose up
```

Так как у `api`, `worker` и `web` в `docker-compose.yml` указано поле
`image:`, `docker compose up` использует уже загруженные образы и не
пытается собирать их заново, поэтому сеть не нужна. Интерфейс открывается
на `http://localhost:8080`.

## Учётные записи

При первом старте, если таблица пользователей пуста, API создаёт четыре
демонстрационные учётные записи, чтобы на проверочном стенде было под кем
войти без участия команды:

| Логин | Роль | Пароль по умолчанию |
|---|---|---|
| `admin` | Администратор | `admin123` |
| `inspector` | Инспектор | `inspector123` |
| `supervisor` | Супервизор | `supervisor123` |
| `ml` | ML-инженер | `ml123` |

Пароли переопределяются переменными окружения `DEMO_ADMIN_PASSWORD`,
`DEMO_INSPECTOR_PASSWORD`, `DEMO_SUPERVISOR_PASSWORD`, `DEMO_ML_PASSWORD`.
Создание происходит только при пустой таблице `users`: как только появляется
хотя бы один пользователь, учётными записями управляют люди, и пересоздание
удалённой демонстрационной учётки при перезапуске отменило бы их решение.

Вход: `POST /api/v1/auth/login` с телом `{ "login": "...", "password": "..." }`
возвращает `{ token, user }`.

- `Задание/` — исходные материалы заказчика.

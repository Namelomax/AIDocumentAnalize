# Документация «Инспектор ИИ»

Короткая карта: что где искать.

- [`../README.md`](../README.md) — обзор проекта, запуск, демонстрационные
  учётки, соответствие ТЗ (что сделано и что нет).
- [`ЗАПУСК_И_ИИ.md`](ЗАПУСК_И_ИИ.md) — подробная инструкция: требования,
  запуск с интернетом и офлайн, подключение языковой модели и модели OCR
  (LM Studio / vLLM), проверка связи, быстрый сценарий, частые проблемы.
- [`Архитектура_Инспектор_ИИ.md`](Архитектура_Инспектор_ИИ.md) — архитектура
  системы: сервисы, хранилища, пайплайн обработки документов.
- [`ТЗ_дизайнеру_Инспектор_ИИ.md`](ТЗ_дизайнеру_Инспектор_ИИ.md) — техническое
  задание на интерфейс, отданное дизайнеру.
- [`../services/web/README.md`](../services/web/README.md) — прототип
  веб-интерфейса (React + Vite): стек, локальный запуск, сборка. На самом
  стенде уже входит в сборку и открывается на `http://localhost:8080` вместе
  со всем остальным — отдельно поднимать не нужно.
- [`../deploy/monitoring/README.md`](../deploy/monitoring/README.md) —
  что именно собирают Prometheus и Grafana, где смотреть дашборд и алерты.
- [`quality/ocr-eval.json`](quality/ocr-eval.json) — результаты измерения
  точности OCR на эталонном комплекте (посчитаны инструментом
  `services/worker/tools/ocr_eval.py`).

Материалы заказчика (ТЗ, Матрица параметров, эталонная разметка) в
репозитории не хранятся — их нет в открытом доступе.

# Инспектор ИИ — сервис автоматической сверки проектной, рабочей и исполнительной документации

Прототип государственной экспертной системы Мосгосстройнадзора для автоматической сверки трёх стадий документации по 132 контролируемым параметрам. Реализован как одностраничное React-приложение на Vite с клиентским стейт-роутингом.

Стек: **React 19 + TypeScript + Vite + Tailwind CSS v4 + lucide-react + pnpm**.

---

## Быстрый старт

Требуется Node.js ≥ 20 и pnpm ≥ 9.

```bash
pnpm install
pnpm dev
```

Приложение поднимется на `http://localhost:5173` (порт Vite по умолчанию).

Сборка production-версии:

```bash
pnpm build
pnpm preview
```

Форматирование исходников:

```bash
pnpm format
```

В случае отсуствия или не возможности запуска через pnpm, можно использовать npm:

```bash
npm install
npm run dev
```

## Карта переходов между экранами

Стейт-роутинг реализован в `src/App.tsx` без внешних библиотек — через `useState<NavState>` и колбэк `onNavigate`. Схема переходов:

```
                                 ┌──────────────────────┐
                                 │  Э1 · LoginScreen    │
                                 │  (auth → main)       │
                                 └──────────┬───────────┘
                                            │ onLogin
                                            ▼
                                 ┌──────────────────────┐
                                 │  Э2 · DashboardScreen│◄──────────────┐
                                 │  таблица объектов    │               │
                                 └──────────┬───────────┘               │
                                            │ onOpenObject            │
                                            ▼                         │
                                 ┌──────────────────────┐               │
                                 │  Э3 · UploadScreen   │───────────────┘
                                 │  3 Dropzone          │  onBack
                                 └──────────┬───────────┘
                                            │ onRunCheck
                                            ▼
                                 ┌──────────────────────┐
                                 │  Э4 · ProcessingScreen│
                                 │  4 стадии, лог        │
                                 └──────────┬───────────┘
                                            │ onComplete
                                            ▼
                      onOpenHypotheses  ┌──────────────────────┐
                ┌───────────────────────│  Э5 · ProtocolScreen │
                │                       │  5 вкладок           │
                ▼                       └──────────┬───────────┘
      ┌──────────────────────┐                     │ onOpenVerification
      │  Э8 · HypothesesScreen│                    ▼
      │  карточки гипотез     │         ┌──────────────────────┐
      └──────────┬───────────┘         │  Э6 · Verification    │
                 │ onPromote           │  3 панели, 7 состояний│
                 └────────────────────►│  CLARIFICATION /      │
                                       │  composite / queue-end│
                                       └──────────┬───────────┘
                                                  │ onFinish
                                                  ▼
                                       ┌──────────────────────┐
                                       │  Э7 · Finalization    │
                                       │  экспорт + ИАИС       │
                                       └──────────────────────┘
```

Все переходы — только через `onNavigate({ screen, objectId?, protocolId? })`, передаваемый в экраны как props. Никаких URL-хэшей, никаких History API — чистая реактивная машина состояний.

## Ключевые правила ТЗ, зашитые в код

| Правило | Где реализовано |
|---|---|
| ИИ не выносит вердикт — только кандидатов | `statusLabels`, колонка «Кандидатов» в Дашборде |
| Красный `#B42318` — только для CONFIRMED_VIOLATION и кнопки «Подтвердить» | `StatusBadge`, `Button variant="danger"`, `EvidencePanel accent="actual"` |
| Приоритет HIGH/MEDIUM/LOW — графит `#475569`, три засечки | `PriorityIndicator` |
| tabular-nums глобально | `font-variant-numeric: tabular-nums` в `body` |
| JetBrains Mono для шифров и SHA-256 | класс `.mono` |
| bbox-оверлей в процентах от подложки | `EvidencePanel` — `left/top/width/height = x * 100%` |
| Решение по кандидату в 2–3 клика, без модалок | `VerificationScreen`, хоткеи `1/2/3` |
| Единственная модалка — финализация | `FinalizationScreen` |
| 5 ошибок загрузки с точным текстом из ТЗ | `UploadScreen`, `useToast` |
| Гипотезы нельзя подтвердить напрямую | `HypothesesScreen` — только «Привязать доказательства» |

## Работа с данными

Все демо-данные вынесены в `src/mocks/data.ts`. Компоненты получают их через props или через импорт из `mocks`. **Никакие тексты не хардкодятся в JSX**.

Что лежит в `mocks/data.ts`:

- `objects` — 8 объектов Мосгосстройнадзора (Алтуфьевское шоссе, Полярная, Октябрьская, Лосевская, УНДМС).
- `findings` — 17 находок: 12 кандидатов (M-002, M-047, M-055, M-118, M-122, …), 3 подтверждённых, 5 гипотез. У M-118 — `composite.atoms`, у M-122 — `clarificationConflict.revisions`.
- `uploadedFiles` — 12 файлов ПД + 5 файлов РД с реальными шифрами (АНО/150321/1-П-АР, АНО/150321/1-РД-ОВ1, …) и сгенерированными SHA-256.
- `protocol` — протокол 2025-0147 со сводкой (132 проверено, 14 кандидатов, 3 подтверждено, 96 без расхождений, 12 без доказательств, 7 неприменимо).
- Словари: `statusLabels`, `processStatusLabels`, `approvalLabels`, `reasonLabels`, `detectionLabels`, `uploadErrors`.

Для интеграции с реальным API замените содержимое этих массивов на результат fetch — интерфейсы типов в `src/types/index.ts` совпадают с контрактом бэкенда.

## Доступность

- Все иконочные кнопки имеют `aria-label`.
- Оверлеи на чертежах помечены `aria-label`.
- Тост-контейнер — `aria-live="polite"`, ошибки — `role="alert"`.
- Модалка финализации — `role="dialog"`, `aria-modal="true"`, `aria-labelledby`.
- Видимый фокус — `outline: 2px solid #1B4E9B` на всех интерактивных элементах.
- Контраст текста и фонов проверен на ≥ 4.5:1 (янтарный `#B54708` на `#FFFAEB`, голубой `#026AA2` на `#F0F9FF`).
